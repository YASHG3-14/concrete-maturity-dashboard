Calculation

M = Σ (T − T₀) × Δt

  • T = measured concrete temperature in °C
  • T₀ = configurable datum temperature in °C
  • Δt = actual elapsed interval between valid readings, converted to hours
  • M = maturity index in °C·hours

The server uses the actual ThingSpeak timestamps, so irregular sampling intervals are handled using their real duration rather than assuming a fixed interval. Readings with missing/invalid timestamps or temperature values are skipped.
